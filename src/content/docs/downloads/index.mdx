PulseRN desktop builds are published through GitHub Releases. Pick the build that matches your
computer, then follow the [installation guide](/PulseRN-Site/installation/) to get connected.

## Run in a browser

With Node.js 22.5 or newer, start the same debugger UI without installing Electron:

```sh
npx @maahibhama/pulsern
```

PulseRN opens an authenticated local browser session and runs until you press `Ctrl+C`. See the
[browser setup guide](/PulseRN-Site/browser/) for Homebrew installation, ports, persistence, and
security details.

## Install with Homebrew

```sh
brew tap maahibhama/pulsern https://github.com/maahibhama/PulseRN
brew install --cask --no-quarantine pulsern
```

## Verify a download

Download `SHA256SUMS.txt` alongside the installer, then run the command for your platform:

```sh
# macOS or Linux
shasum -a 256 -c SHA256SUMS.txt
```

```powershell
# Windows PowerShell
Get-FileHash .\PulseRN-*-setup.exe -Algorithm SHA256
```

Compare the Windows result with the matching line in `SHA256SUMS.txt`. If a checksum differs, do
not open the file; delete it and download it again from the official release.
