PulseRN Open-source React Native debugger

Hi there,

I built a debugger that keeps the React Native story together.

I’m Mahendra, the creator of PulseRN. I built it because debugging a React Native issue often means jumping between console output, network requests, state tools, navigation events, and error traces—then trying to reconstruct what happened from memory.

PulseRN brings those signals into one chronological desktop timeline, so developers can move from the visible symptom to the event that caused it.

What it brings together

✓ Console, network, Redux, navigation, performance, and errors
✓ Hermes debugging with original TypeScript sources
✓ Local-first sessions with configurable redaction
✓ Expo development builds and bare React Native apps
✓ MCP workflows for evidence-backed AI debugging

PulseRN is open source and actively evolving. I’m reaching out because your experience in the React Native community would make your feedback especially valuable. If you have a few minutes to look at the project—or try it with a development app—I’d love to hear what feels useful, what is missing, and where the workflow could be clearer.
